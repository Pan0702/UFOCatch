DirectXとC++を用いて個人で開発したゲームです。ゲーム内容としては、UFOが人間に見られないように動物を吸い込み、吸い込んだだけUFOの力が強くなっていくゲームです。
学校で用意されたライブラリ（フレームワーク）を使用しています。
 
プロジェクトファイル上では、プロジェクトファイル上ではフォルダのEnemies,Player,Scene,System,Tutorial,Stage,とUtilsの一部のスクリプトを独自に制作しています。
特に工夫し、こだわった部分は下記3点です。
 
(1)当たり判定の削減
4分木をつかって当たり判定の計算回数を減らしました。管理にはモノトーン曲線をつかい1次元配列で管理しました。1次元で管理することでメモリの削減やデータにアクセスしやすくなります。
そのおかげで計算量が以前の約80～90％削減することができました。

(2) 扇形（Sector）と円（Circle）の衝突判定アルゴリズムを実装した。
判定ロジックは5段階あります。
1つ目は距離の2乗で早期リターン（遠すぎる場合を除外）、
2つ目は円の中心が扇形内か（距離 + 角度判定）、
3つ目は円が扇形の円弧と交差するか、
4つ目は扇形の2辺（境界線）と円が交差するか（二次方程式で解く）、
5つ目は扇形の頂点が円内かです。
技術的工夫:
線分×円の交差判定：パラメトリック方程式を円の方程式に代入し、判別式 D=b²-4ac で交点の有無を判定しました。
sqrt()を使わず距離²で比較することで計算コストを削減しました。
（3）ステートパターンによる敵AIシステム
設計: State PatternとComponent Patternを組み合わせた3層アーキテクチャを採用しました。
Object層（CEnemyBase）では コンポーネントのライフサイクル管理、物理演算、衝突判定を行います。
State層（CBaseState）では Enter/Update/Exitによる状態遷移制御、次状態のキュー管理を行います。
Component層（CComponentBase）では 各行動（CWalk, CIdle, CSuction等）の具体的実装をしました。
CWalkコンポーネントを4種類の敵で共有でき、新規敵追加時のコード量を約60%削減することができました。また状態遷移のバグも局所化され、デバッグ効率が向上しました。
