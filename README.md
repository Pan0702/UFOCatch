DirectXとC++を用いて個人で開発したゲームです。ゲーム内容としては、UFOが人間に見られないように動物を吸い込み、吸い込んだだけUFOの力が強くなっていくゲームです。
学校で用意されたライブラリ（フレームワーク）を使用しています。
 
プロジェクトファイル上では、○○フォルダ＞07_Titleから10_Stageのスクリプトを独自に制作しています。
特に工夫し、こだわった部分は下記3点です。
 
(1)軽量で高精度なゲームロジック
人型NPCの視界にUFOが入っているかを判定する機能を実装しました。正面ベクトルとNPCからUFOへのベクトルを正規化し、内積を用いて角度を算出することで、方向性を持った視界判定を実現しました。
 
異なる高さの動物を地面経由でUFOまで引き寄せる処理を実装しました。UFOと動物を結ぶ線分が地面と交わる点を内分比で算出し、その点からの移動ベクトルを決定しています。DeltaTimeを乗算することでフレームレートに依存しない動作を実現しました。FPSが変化しても吸い込みスピードが一定で、自然な吸い込みができるようになりました。
（2）ステートパターンによる敵AIシステム
ActorとStateを分離し、ステートはstd::unordered_mapで管理しました。 Actorでステートを切り替え、Stateでは振る舞いをclassごとに分けて実装しました。 単一責任の原則に基づき、新たな行動の追加や修正が容易になりました。
 
すべてのステートをコンストラクタで生成し、std::unordered_mapで保持するようにしました。 new/deleteを頻繁に行わないことで、状態が遷移する時の動的確保をなくしました。 その結果、ステートが切り替わってもフレームレートが変化しにくくなりました。
（4）lizardの利用
関数の可読性を上げるため、関数を小さく保つようにしています。循環的複雑度を測るツール「lizard」を導入し、循環的複雑度の値をできる限り低くするように意識しています。
 
この取り組みにより、関数の複雑さが客観的に数値で分かります。循環複雑度の値を低くするためには、関数を小さくする必要があります。結果としてコードの可読性が向上します。また、小さな関数はバグが混入しにくく、テストが書きやすいです。lizard を活用してコードの複雑度を管理することは、保守性が高く、変更に強い「クリーンなコード」を維持するための強力な基盤となります。
