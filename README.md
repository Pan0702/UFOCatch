開発環境 DirectX11, C++
製作期間 1か月

この作品は、DirectXとC++を用いて個人で開発したゲームです。人にばれないように動物を吸い込むゲームです。

プログラムには学校で用意されたライブラリ(フレームワーク)を使用しています。ゲームの主要な実装部分については全て自分で実装しました。
プロジェクトファイル上では、フォルダの06_共通　から　09_Enemyのスクリプトを書きました。

特に力を入れたことは、以下の4つです。
1. 範囲内の判定
  人の視界にUFOが入っているかは、正面ベクトルと人からFUOへのベクトルの2つを正規化し、内積を用いて角度を求めるプログラムを実装しました。
2．吸い込み処理
　比率を使いプレイヤーと動物を結ぶ線が地面と交わる点を求めその点からUFOまでのべクトルを求めました。移動速度が求まったらDeltaTIimeを使ってフレームレートが変わっても使えるようにほせいしました。
3. State管理
　敵の行動Stateをクラスで分けました。行動ごとにクラスを作りどこでどんな行動をしてるかわかりやすくしました。Stateを変える場所は同じにし、どこでStateが変化するのかわかりやすくしました。
4. コードの分割
　1つ1つ関数が大きくなると可読性が下がってしまうので循環的複雑度を測るためのツールを導入し、循環的複雑度がをできる限り低くしました。

短期間である程度完成まで行けたと思いました。
オブジェクトを沢山出すゲームなので今後の目標は四分木を使ってオブジェクト管理をし、メモリの使用量を下げていきたいです。
